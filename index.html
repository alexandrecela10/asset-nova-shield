Quality gates

Every node has a testable quality gate. The eval suite runs on a golden set of confirmed events.

LLM Threat detection recall

Target: 100% recall; maximize precision progressively

Missing a real threat is unacceptable. False alarms are tolerable early and reduced over time through the self-improving loop.

Test: 50 site reports from closed project. Expert labeled 8 real threats, 42 non-events. Agent must flag all 8. Precision starts at whatever level catches them all, then improves as dispositions accumulate.

Code Citation accuracy

Target: 99.5%

Every citation must resolve to an actual document, section, and page.

Test: Agent cites "Clause 4.12, p.88". Verifier opens the contract, confirms clause exists at that page.

Code Deadline accuracy

Target: 100%

Date math is code, never LLM. Zero tolerance for errors.

Test: Event date = 4 Aug, contract says "21 days", Amendment overrides to "14 days for Areas 6-8". Expected: 18 Aug.

LLM Hallucination in drafts

Target: 0 in approved outputs

Every sentence must trace to a source. Citation verifier + human review = double barrier.

Test: Agent writes "as stated in letter C-1205". Verifier checks: does C-1205 exist? If not, draft is blocked.

LLM Defense position accuracy

Target: 80% agreement

"Owner advantage" vs "supports contractor" tagging must match expert assessment.

Test: 6 documents from a resolved dispute. Expert tagged 3/3 split. Agent must agree on at least 5 of 6.

Human Draft approval rate

Target: 70% approved

If the team rewrites most drafts, the agent isn't learning their style. Edit diffs feed the loop.

Test: After 4 weeks, of the last 20 drafts, at least 14 approved as-is or with minor edits.

Gets smarter on your project, without your data leaving.

Thresholds, templates, golden set

Dismissals reduce noise

When the team dismisses a false alarm, Shield raises its threshold for that pattern. Fewer irrelevant flags over time.

Edits sharpen drafts

When the team rewrites a response before sending, the edit diff is captured. Draft quality improves to match how the team writes.

Approvals confirm what matters

Confirmed events grow the golden eval set. No update ships unless it passes on all confirmed events. The test suite gets harder over time.

Full sovereignty: all retraining happens inside the customer's environment (in-region VPC or on-prem). Dispositions never leave. Your project data never improves someone else's agent. No shared model, no data export, no cross-tenant learning.
